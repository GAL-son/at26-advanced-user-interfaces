# at26-advanced-user-interfaces
Course work for Advanced User Interfaces at Akademia Tarnowska (2026)

## Getting Started

Short instructions to run the project locally.

Requirements:

- Node.js (recommended: v18 or newer)
- npm (bundled with Node.js)

Steps:

1. Install dependencies:

```bash
npm install
```

2. Start the development server (app will be available at `http://localhost:3000`):

```bash
npm run dev
```

3. (Optional) Build and run in production mode:

```bash
npm run build
npm run start
```

Environment variables note:

- Do not commit `.env*` files — they are ignored by `.gitignore`.
- For local variables create a `.env.local` file and add your values there.

Important files in this repo:

- `package.json` — scripts and project dependencies.
- `next.config.mjs` — Next.js configuration.
- `app/` — application source (Next 13+ app router).
